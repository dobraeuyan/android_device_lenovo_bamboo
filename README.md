Device Tree for Lenovo Yoga Tab 3 (bamboo)
=====================================

The Lenovo Yoga Tab 3 (codenamed _"bamboo"_) is a low-range tablet from Lenovo.
It was released in October 2015.

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Quad-core 1.30GHz
Chipset | Qualcomm MSM8909 Snapdragon 210
GPU     | 400MHz Adreno 304
Memory  | 1 GB (LPDDR3)
Shipped Android Version | 5.0.1
Storage | 16 GB
MicroSD | Up to 200 GB
Battery | Li-Ion 6200 mAh (non-removable)
Display | 1280x800 pixels, 8" (~190 PPI) / 10" (~150 PPI)
Rotating Camera  | 10 MP
